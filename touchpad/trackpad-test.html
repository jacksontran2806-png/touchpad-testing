What this actually tests

Your trackpad doesn't send "gestures" to the browser — it sends cursor movement plus wheel-scroll events, the same as a mouse. Two-finger scroll and pinch-to-zoom are the OS translating multi-touch input into those same signals before the browser ever sees raw touch data. This tool shows exactly what arrives at that level, so a gesture that never lights up here has failed before it reached the browser at all.

If something doesn't register

  1. Confirm the trackpad is enabled and not disabled by an external mouse setting.
  2. Update or reinstall the trackpad driver (Windows) or reset trackpad settings (Mac).
  3. Check that gestures like pinch-to-zoom are actually turned on in system settings — many are off by default on Windows.
  4. Test on another computer if possible, to rule out a hardware fault versus a software/driver issue.
