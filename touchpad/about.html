About Hardware Test Hub

A free, no-install way to check your input devices

Hardware Test Hub is a set of small, focused tools for checking whether your mouse, keyboard, or trackpad is actually working the way it should — every click, keypress, and scroll shown live, the instant it reaches the browser.

Why this exists

"Is my mouse broken, or is this just a game/app being weird?" is a surprisingly hard question to answer without a dedicated tool. Operating systems and applications add their own layers of interpretation on top of raw input, so a click that "does nothing" could be a dead switch, a driver issue, a disabled setting, or software eating the input entirely. These tools sit as close to the raw signal as a browser can get, so you can tell those apart quickly.

How it works

Every tool runs entirely in JavaScript, in your browser, using standard web APIs — Pointer Events for clicks and movement, the Wheel event for scrolling, and the Keyboard Events API for keys. Nothing about your inputs is sent anywhere or stored; when you close the tab, the results are gone. There's no account, no install, and no app to keep updated.

What's here

Mouse, keyboard, and trackpad testers for the basics — clicks, keys, and gestures — plus more specific tools for double-click misfires, scroll consistency, keyboard rollover, click speed, and reaction time. Each tool page also explains what it's actually measuring and what to do if something looks wrong, and the guides section covers the most common fixes in depth.
