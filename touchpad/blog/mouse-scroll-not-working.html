Mouse Scroll Not Working? Here's How to Fix It

Updated August 2026 · 5 min read

Scroll problems fall into a few distinct patterns — dead, reversed, jumpy, or skipping — and each points to a different cause. Identify yours below, then work through the matching fixes.

First, see exactly what your wheel is sending.

Run the scroll test →

1. Scrolling does nothing at all

Check Device Manager (Windows) or System Settings → Mouse (Mac) to confirm the mouse is recognized at all — a completely dead wheel alongside working buttons usually means a connection issue at the wheel's encoder inside the mouse, not a driver problem. Try the mouse on another computer to rule out a software conflict before assuming hardware failure.

2. Scroll direction is reversed

This is almost always a setting, not a fault. On Windows, check Settings → Bluetooth & devices → Mouse → additional mouse settings for a "reverse scrolling direction" option. On Mac, check System Settings → Trackpad/Mouse → Scroll direction: Natural — toggling this affects mice too. If the test above shows a consistent deltaY sign that's simply "backwards" from what you expect, this setting is the fix, not a hardware problem.

3. Scrolling is jumpy or skips lines

Run the scroll test above and watch the event log. Evenly-sized deltaY values that occasionally jump much larger than the rest point to a wheel encoder that's starting to fail — the mechanical detents inside the wheel are what produce those even steps, and wear makes them inconsistent. Clean around the wheel with compressed air first; if the erratic jumps continue, it's usually a hardware wear issue rather than something a driver update fixes.

4. Scrolling is fine but "too fast" or "too slow"

This is a sensitivity setting, not a fault: Windows' "lines to scroll" setting (Settings → Bluetooth & devices → Mouse) and most vendor software (Logitech Options+, Razer Synapse) let you adjust how many lines or pixels each notch scrolls.

5. Update or reinstall the mouse driver

For a generic HID mouse, Windows and macOS both include built-in scroll support with no separate driver needed — if scrolling misbehaves, the fix is almost always in settings, not a driver reinstall. For mice with dedicated software (gaming mice, ergonomic mice with extra buttons), reinstalling that vendor software can resolve a corrupted configuration that's affecting scroll behavior specifically.

6. Rule out the wheel encoder itself

If cleaning and settings don't help and the scroll test consistently shows erratic, inconsistent deltas even during slow, deliberate scrolling, the mechanical encoder inside the wheel has likely worn out. Unlike click switches, wheel encoders are less commonly a simple solder-in swap — for most mice, this means it's time to replace the mouse.
