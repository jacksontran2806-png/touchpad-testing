Keyboard Disconnects and Reconnects Randomly Over USB

Updated September 2026 · 6 min read

You know the sound. The descending two-tone USB chime, the keyboard going dead for a second or two, then the ascending chime as it comes back. Sometimes once an hour, sometimes every few minutes, sometimes only when you are in the middle of something.

The keyboard is rarely the thing at fault. In roughly this order, the causes are: Windows power management suspending the port, a cable that is marginal rather than broken, an overloaded or flaky port, and — a distant fourth — the keyboard itself.

A test that saves you an hour

Before changing settings, establish whether the disconnects follow the keyboard or the port. Move the keyboard to a different USB port, ideally on a different side of the machine or a different controller, and use it normally for a few hours.

If the disconnects stop, the original port or its controller is the problem and you can skip most of what follows. If they continue, keep reading — and note which it was, because it changes what is worth trying.

Where possible, also try the keyboard on a completely different computer. It is the cleanest split between "this keyboard" and "this PC" you can get.

1. Stop Windows suspending the port

This is the most common cause on desktops and laptops alike, and there are two separate settings that both need changing. People change one, see no improvement, and conclude it was not the cause.

Device Manager. Right-click Start → Device Manager → expand Universal Serial Bus controllers. For every entry named USB Root Hub or Generic USB Hub, open Properties → Power Management tab → untick Allow the computer to turn off this device to save power. Do it for all of them, not just one. Then do the same under Keyboards for your keyboard entry.

Power plan. Control Panel → Power Options → Change plan settings → Change advanced power settings → USB settings → USB selective suspend setting → set to Disabled. On a laptop, set it for both On battery and Plugged in.

Restart afterwards. If the disconnects stop, that was it — and note that Windows updates sometimes reset both of these, so if it comes back in six months, check here first.

2. Replace the cable — properly

If the keyboard has a detachable cable, this is the highest-value thing you can test, because a bad cable produces exactly this symptom and costs nothing to rule out.

USB-C connectors on keyboards take a lot of abuse. The cable gets yanked, the connector flexes, and eventually one conductor makes intermittent contact — enough to work most of the time, and enough to drop out when the cable moves or warms up.

Test by swapping in a known-good cable, ideally a short one. Then, with the original cable back in, gently flex it near each end while watching for a disconnect. If you can provoke a dropout by moving the cable, you have found it.

Where the cable is captive, check the strain relief where it leaves the keyboard body for kinks or a visibly stretched section.

3. Deal with the port and the hub

Unpowered USB hubs cause an enormous share of these reports. A hub splits one port's power budget among everything plugged into it, and an RGB keyboard is a heavy consumer. Plug the keyboard directly into the computer.

Front-panel ports are the next suspect. They run through an internal cable to a motherboard header, and a loose header or a cheap case cable produces intermittent drops that rear ports do not have. Use a rear port for a few days as a test.

Also worth knowing: USB 3.0 ports emit interference in the 2.4GHz band. If your keyboard is wireless with a USB dongle, plugging that dongle into a USB 3.0 port right next to an external drive is a classic cause of dropouts. Move the dongle to a USB 2.0 port, or use an extension cable to get it away from the machine.

4. Check what the disconnect actually looks like

Windows Event Viewer will tell you more than the chime does. Open it, go to Windows Logs → System, and filter for events around the time of a disconnect. Repeated entries mentioning USB device enumeration failures point to a hardware or power problem; nothing logged at all points more towards a driver.

It is also worth confirming what state the keyboard is in when it "reconnects". Open the keyboard test and leave it open while you work. After a dropout, check whether every key still registers — a keyboard that comes back with a stuck modifier or dead keys is a different and more serious problem than one that simply reconnects cleanly.

5. Less common causes worth knowing

Insufficient power supply. On a desktop with a marginal or ageing PSU, USB voltage can dip under load. If the disconnects correlate with the GPU spinning up, this is worth considering.

Motherboard USB controller driver. Chipset drivers matter here more than people realise. Get the current chipset package from the motherboard manufacturer rather than relying on what Windows Update supplies.

A failing keyboard controller. Real, but rare, and it is where you land after eliminating the rest. If the keyboard disconnects on multiple computers, with multiple cables, on multiple ports, the keyboard is the problem.

Heat. If dropouts only start after an hour of use, thermal expansion on a marginal solder joint is a genuine possibility — inside the keyboard, or at the port.

FAQ

Why does my keyboard disconnect only when gaming?

Two likely reasons. System power draw peaks under load, so a marginal supply or port sags exactly when the GPU ramps up. And you move the keyboard more while gaming, which provokes an intermittent cable.

Test by running something GPU-heavy without touching the keyboard. If it still drops, it is power rather than movement.

Does disabling USB selective suspend hurt anything?

Only battery life on a laptop, and only slightly — you are preventing idle USB devices from powering down.

On a desktop the impact is negligible. It is a reasonable setting to leave disabled permanently if it solves the problem.

Could a USB hub really cause this?

Very easily, and unpowered hubs are one of the most common causes. A hub shares a single port's power budget across everything connected, and an RGB keyboard is a heavy draw.

Plug the keyboard straight into the computer for a few days. If the drops stop, either use a powered hub or keep the keyboard on a direct port.

My wireless keyboard drops out too. Same causes?

Some overlap, but add interference. USB 3.0 ports and drives emit noise in the same 2.4GHz band most wireless keyboards use, and a dongle sitting next to one will drop out regularly.

Move the dongle to a USB 2.0 port, or use a short extension cable to get it clear of the machine. Also rule out low batteries, which cause intermittent dropouts long before the keyboard dies completely.
