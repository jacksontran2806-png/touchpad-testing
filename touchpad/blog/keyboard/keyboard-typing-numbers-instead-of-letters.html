Keyboard Typing Numbers Instead of Letters? Turn Off Num Lock

Updated September 2026 · 6 min read

You type milk and get 6035. The letters that misbehave are always on the right-hand side of the keyboard — U, I, O, P, J, K, L, and M — while the left half types perfectly. That pattern is the giveaway: a hidden numeric keypad is switched on over your letter keys.

This is Num Lock, and on a laptop without a physical number pad it is one of the easiest settings to enable by accident and one of the hardest to find. Nothing is broken, and the fix is a single key combination once you know your laptop's version of it.

Why the overlay exists

Before laptops had room for a full-size deck, manufacturers printed a compact numeric keypad onto the right-hand letter keys: 7, 8, 9 on U, I, O; 4, 5, 6 on J, K, L; 1, 2, 3 on M and the two keys beside it. Num Lock switched the block between letters and digits so accountants and data-entry users could work without carrying a separate keypad.

Wide screens made room for real number pads on larger laptops, but the feature never left the firmware. Many current 13- and 14-inch laptops still carry the overlay while no longer printing the secondary digits on the keycaps — which is why the behaviour looks like a hardware fault rather than a toggle. Compact mechanical keyboards, 60 and 65 percent boards in particular, have the same feature for the same reason.

You can confirm this in seconds on the keyboard test. With the overlay active, pressing J lights up the numpad 1 position rather than the J position: the keyboard is genuinely reporting a different key, not producing a wrong character from the right key. That distinction separates a Num Lock overlay from a layout mismatch, where the physical position stays correct and only the character is wrong.

1. Toggle the overlay off with the Fn shortcut

Look at your keyboard for a key labelled NumLk, Num Lock, or a small keypad icon. On laptops it is usually a secondary function printed in a different colour on F-row keys or near Backspace, Scroll Lock, or Insert. Hold Fn and press it.

If you cannot find it, the shortcut by brand is usually one of these:

  • HP, Acer, Asus: Fn + NumLk, often on F11; some Asus models use Fn + Insert.
  • Dell: Fn + F4 on recent models, or Fn + Shift + NumLock on older ones.
  • Lenovo and ThinkPad: Fn + F8, or Shift + NumLock.
  • Toshiba and Dynabook: Fn + F11.
  • Compact mechanical keyboards: Fn + NumLock, or a dedicated combination in the manual — Fn + Del and Fn + Home are both common.

Watch for a small indicator light, usually a padlock with a 1 inside it, on the key itself or along the edge of the deck. On laptops with no light, a notification may appear on screen instead. Press the combination once, then type a few right-hand letters to test — do not press it repeatedly, because you will simply toggle back and forth.

2. Use the On-Screen Keyboard when there is no Num Lock key

Some compact laptops and tenkeyless keyboards have no Num Lock key at all, which leaves an active overlay with no obvious way to switch it off. Windows can send the signal for you:

  1. Press Win + Ctrl + O to open the On-Screen Keyboard.
  2. Click Options, in the lower right of the on-screen keyboard.
  3. Tick Turn on numeric key pad, then click OK.
  4. A keypad appears on the right of the on-screen keyboard. Click the NumLock button there; if it is highlighted, clicking turns the overlay off.
  5. Type a few letters on your physical keyboard to confirm, then close the on-screen keyboard.

The On-Screen Keyboard sends the same signal as a physical key, so this clears the state on any keyboard, including one that has no Num Lock key. It is also a useful fallback when the physical key exists but is itself broken.

3. Stop Num Lock turning itself on at startup

If the overlay returns after every restart, something is deliberately restoring it. There are two places to check, and it is worth doing both, because they act independently.

Windows sign-in state. Windows restores the Num Lock state from a registry value at sign-in. Press Win + R, type regedit, and press Enter. Navigate to HKEY_USERS\.DEFAULT\Control Panel\Keyboard and open InitialKeyboardIndicators. Set it to 0 to start with Num Lock off, or 2 to start with it on, then restart. As with any registry edit, change only the value you came for.

BIOS or UEFI. Firmware can set Num Lock on before Windows ever loads, which overrides the registry value. Restart, enter setup with the key shown on the startup screen — commonly F2, F10, or Del — and look for Boot Up NumLock Status, NumLock State, or similar under a Boot or Advanced tab. Set it to Off and save.

There is one more possibility worth ruling out on a laptop: an external USB keyboard or a docking station with its own Num Lock state can impose that state on the laptop's built-in keyboard. If the problem only occurs at your desk, unplug the external keyboard and test.

4. Rule out Mouse Keys on macOS

macOS has no Num Lock overlay for letter keys, so on a Mac the cause is different. The usual culprit is Mouse Keys, an accessibility feature that converts part of the keyboard into pointer controls — keys stop producing characters and start moving the cursor instead.

Open System Settings → Accessibility → Pointer Control and make sure Mouse Keys is off. Also check Keyboard → Input Sources for a layout you did not add, and look in the Keyboard settings for a modifier remapping that has redefined a key. On a Mac using a Windows keyboard over Bluetooth, a Num Lock state set on that keyboard can also carry across; toggle it on the keyboard itself.

5. When it is not Num Lock

If left-hand letter keys are affected too, or the characters are symbols rather than digits, the overlay is not your problem.

A stuck Shift key makes the number row produce ! @ # and can disturb other keys. Press and release both Shift keys firmly, then check the modifier indicators on the keyboard test to confirm nothing is being held down.

A wrong keyboard layout produces wrong characters across the whole board rather than in one cluster. On Windows, check Settings → Time & Language → Language & Region; on macOS, System Settings → Keyboard → Input Sources. An accidental Win + Space is the usual cause.

A corrupted keyboard driver is the last thing to suspect, not the first. On Windows, open Device Manager, expand Keyboards, right-click the entry and choose Uninstall device, then restart — Windows reinstalls the standard driver automatically. Do this only after the layer and layout checks above, because it fixes far fewer cases than people expect.

FAQ

Why does Num Lock turn itself on every time I start Windows?

Windows restores the Num Lock state at sign-in from a registry value, and some firmware sets it at boot as well.

For the Windows side, open regedit, go to HKEY_USERS\.DEFAULT\Control Panel\Keyboard and set InitialKeyboardIndicators to 0 for off or 2 for on. If it still returns, look for a "Boot Up NumLock Status" option in your BIOS or UEFI setup.

Why do laptops without a number pad have Num Lock at all?

It is a holdover from before laptops had room for a full-size deck. Manufacturers printed a compact keypad onto the right-hand letter keys — 7, 8, 9 on U, I, O and 4, 5, 6 on J, K, L — so data entry was possible without an external keypad.

Modern laptops still carry the feature in firmware even when the secondary digits are no longer printed on the keycaps, which is exactly why it surprises people when it switches on.

What if my keyboard has no Num Lock key?

Use the Windows On-Screen Keyboard. Press Win + Ctrl + O, click Options, tick "Turn on numeric key pad", then click the on-screen NumLock button to toggle the state.

It sends the same signal as a physical key, so it clears the overlay on any keyboard — including one that never had a Num Lock key, or one where the key itself has failed.

Do Macs have a Num Lock overlay?

No. macOS has no Num Lock overlay for letter keys.

If letter keys on a Mac produce numbers or move the pointer, the usual cause is Mouse Keys, an accessibility feature that turns part of the keyboard into pointer controls. Turn it off under System Settings → Accessibility → Pointer Control.

Could this be a virus or malware?

Almost never. Letters becoming numbers in one specific cluster on the right-hand side is the exact signature of the embedded keypad, not of malware.

Work through the Num Lock toggle, the layout check, and the modifier check first — in practice one of those explains it every time.
