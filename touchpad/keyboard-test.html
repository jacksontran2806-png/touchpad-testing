What this actually tests

Every key sends a physical position (event.code, like KeyQ) and, separately, the character your OS layout maps it to (event.key). This tool lights up the physical position and relabels it for the layout you pick — so you can tell a genuinely dead key apart from a layout mismatch, which is the single most common reason "half my keyboard" seems broken.

If a key doesn't respond

  1. Confirm your OS keyboard layout matches your physical keyboard — a mismatch, not a dead key, is the most common cause.
  2. Check for debris under the keycap; compressed air clears most of it.
  3. Test on another computer or via a USB keyboard to rule out the port or driver.
  4. For a mechanical board with custom firmware, reset to factory defaults before assuming hardware failure.
