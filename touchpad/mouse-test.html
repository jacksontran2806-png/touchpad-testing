What this actually tests

The browser sees mouse buttons as numbered inputs, not physical parts — button 0 is left, 2 is right, 1 is the wheel, and 3/4 are the thumb buttons. This page reports what actually arrives at that level, so a button that never registers here has failed somewhere between the switch and the driver, not in your software.

If a button doesn't respond

  1. Try a different USB port, and a different cable if it has one.
  2. Test on another computer — that separates the mouse from the driver.
  3. Check the vendor software. Side buttons are often remapped to nothing by default.
  4. Reinstall the driver, then re-run this test before buying a replacement.
